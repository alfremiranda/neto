Mobile action menu for a list row. State = Default | Confirming. Deleting takes two taps and the sheet stays open between them: the first tap turns the row red and rewrites it. There is no modal — the confirmation happens in place, so the user never loses sight of which entry they are deleting. Desktop uses inline row actions instead; this component does not appear there.
