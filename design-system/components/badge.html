Generic label chip. Variant × Tone × Icon. Variant=Filled paints badge/{tone}/background; Variant=Outline paints badge/{tone}/border with no fill. Same geometry, same six token families — this used to be two component sets (Badge filled, Status outline), and the filled one had zero instances in the whole file. Filled and outline are a treatment, not two components. Outline is the entry-state treatment: scheduled, unconfirmed, overdue. Filled is a plain label. Colour here is decorative. The moment a badge carries meaning — an account, a category, a currency — use the specific component instead, so the semantic token layer stays the source of that meaning. AccountBadge is the worked example: it exists precisely because a generic Badge was carrying an account name.
