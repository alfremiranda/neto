A single choice among options, drawn as a row. It is a radio in row form: the choice is exclusive and the state lives in the group, so it carries the system Radio instead of drawing its own mark. Show media turns on the leading tile — use it when the options are kinds of thing rather than values, because an icon is what gets scanned before the words. Show description turns on the second line; a row with no description is a value, a row with one is a decision. State and Selected are separate axes and are visible at the same time. Focused is the two-ring shadow, the same one CurrencyRadio uses; it never replaces the selection.
