Empty state for a list that has no entries yet. Media = Icon | None. The dashed border is deliberate: it says "this container is real but has nothing in it", which a solid border would not. It is the one place in the system that uses a dash. Always carries an action. An empty state without a way out is a dead end — if there is genuinely nothing to do, use plain text instead of this component.
