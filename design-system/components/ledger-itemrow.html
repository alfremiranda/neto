One entry in an account’s ledger. The five sibling rows each show one KIND of thing in its own view; this one shows whatever the account did, in date order, so a single row has to carry an income, an expense, both legs of a transfer and a social-security payment. That is why the leading mark is a nested LedgerEntryIcon swap and not an axis. Six entry types times the axes below would be sixty variants for a fact the entry already carries. Three axes, and the matrix is deliberately sparse: · Device — which trailing controls the row offers. Desktop edits and deletes in place; Mobile opens RowActionsSheet behind one button. · Flow — Credit prints the sign and paints the amount fg/provision; Debit leaves it fg/default. This is the one thing the siblings never needed, because each of them only ever moves money one way. · State — Default, Scheduled, Confirming. Confirming is Desktop only: it is the inline delete confirmation, and Mobile confirms inside the sheet. There is no Pressed, which the siblings do have, because this row has no pressed styling in code — the mobile tap opens the sheet and nothing else happens. Scheduled is a state of the ENTRY, not of the row: the whole row drops to 60%, the mark becomes the clock whatever the type underneath, and the “Programado” badge appears next to the description. Two measurements are load-bearing. The amount column is pinned to 104 so a leading “+” does not shift the column between neighbouring rows — a ledger is read down the right edge. And the badge never shrinks: the description’s cap is derived per variant from what is actually left after the mark, the amount column and that variant’s own actions, so on Mobile + Scheduled the description truncates and the badge stays whole. A truncated badge reads as a different word. OPEN for Dev — four measurements where this row follows the row family and the code does not. None of them is this row’s invention: · description Body/Base-Emphasis (16 Medium); code passes ts-body-base (16 Regular). · running balance Amount/Micro (12); code passes a raw 10px. 10 is not a rung on the type scale. · action buttons Icon Button Size=LG (36); code passes size md. · row height 62; code sets min-h 52. The 62 falls out of the family’s padding, it is not set.
