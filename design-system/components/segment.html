One segment of a segmented control. Compose them inside SegmentedControl — a segment on its own is not a control. Selected paints bg/brand with primary-foreground text; Default and Hover have no fill and differ only in text colour. There is deliberately NO Disabled state: the two segmented controls in the product (account type, currency) never disable a segment, and designing one would be inventing a state nobody asked for. Built 2026-08-17 from OnboardingView.tsx, where this control was hand-rolled twice out of raw button elements with two different paddings. This unifies them at 10/6; if a tighter one is genuinely needed it comes back as a Size property, not as a second drawing.
