The tinted bubble that opens every ledger row: a 32px circle in a subtle background token with a 16px glyph in the matching foreground token. Six types, one nested swap — putting them on LedgerRow instead would multiply every row state by six for a decision the entry already carries. Two glyphs do double duty. income and transfer-in share arrow-down-left; egreso and transfer-out share arrow-up-right. Colour is the only thing separating each pair inside the bubble, so it is never the only carrier in use: the row prints “Desde {cuenta}” or “Hacia {cuenta}” for a transfer and the entry description for the rest (WCAG 1.4.1). scheduled OVERRIDES the type rather than sitting beside it. A scheduled entry shows the clock on the neutral tint whatever it is underneath, because at that point what matters is that it has not happened yet. The row also drops to 60% and prints the “Programado” badge. Glyph contrast is measured against its own tint in both modes: Light floor 3.58:1 (income), Dark floor 5.84:1 (egreso). A filled glyph is a graphic object, so 1.4.11 applies. The glyph is 16 (icon-size/md), not the 14 the code passes. 14 is not a rung on the icon scale — 12 · 16 · 20 · 24 — and a one-off would flatten the scale for one row. OPEN for Dev: the ss bubble in code paints its glyph with --color-tax, which resolves to bg/tax (amber/400) and measures 1.61:1 on amber/50 in Light. That fails 1.4.11. Figma uses fg/tax (amber/700, 4.84:1); the published name is --color-tax-txt.
