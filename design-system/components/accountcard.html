Account card. Type × State. Each type shows different data, which is why this is one set and not four components: Bank Account adds the estimated monthly yield, Credit Card shows limit, debt, % used and the cut/payment dates, Savings shows the CDT maturity countdown, Cash has neither number nor rate. The account type is locked after creation — to reclassify, the account must be recreated. The card never needs to handle a type change. The banner carries the account accent. At runtime that fill comes from the USER’S DATA — each account stores a hue picked from account/{hue}/accent — so account/purple/accent is the canvas default, not a decision. Repointing it to a fixed colour breaks user-chosen account colour. The palette is twelve account/{hue}/accent + /surface pairs; the picker is AccountColorPicker. See design-system/docs/25-account-color.md. 2026-08-17: was bound to color/purple/500, a raw primitive inside a component, across all 12 variants.
