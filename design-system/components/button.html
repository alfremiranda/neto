Primary action control. Variant × Severity × Size × State. Filled = the single main action on a screen. Outline = secondary. Ghost = tertiary and inline actions. Severity=Danger is only for destructive actions, which must follow the two-tap confirm pattern: first tap shows "¿Eliminar?", second deletes. Never delete on one tap. Labels use Control/SM–XL, whose line height is 100% so the text centres in the frame.
