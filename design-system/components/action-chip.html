Filter chip with an optional count badge. State × Badge. Used for the expense category filter. Only categories that have data that month are rendered, so the strip length varies. State=Selected is the active filter; Badge=True shows how many entries match. Selected has its own three tokens (action-chip/selected/*). The other three states still borrow badge/neutral/* and badge/accent/*, which is a loan, not a decision — a filter chip is not a badge. Authorised to finish on 2026-08-19, still open.
