Amount field. State × Label. Always tabular — Rethink Sans is tabular by default, so figures do not jump while typing. The Hint line is not decoration: it shows the live conversion when the amount is entered in the other currency, using that month's TRM. Error replaces it rather than stacking, so the field never changes height between the two. Height comes from input/size/md/height so it lines up with Input, Select and DatePicker in the same row.
