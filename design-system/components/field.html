A form field: the label, the control, and the message. Built 2026-08-20 because the system had four form components and four different answers about labels — Input, Select and DatePicker had none at all and were letting the placeholder do the job, at 2.56:1 contrast and gone as soon as the user types. The control is an INSTANCE SWAP: swap in Input, Select or anything else — including an Input configured as a date or money field, which is what replaced DatePicker and MoneyInput. The field’s own visual state (focus, disabled) belongs to the control; this wrapper only knows whether the message is a hint or an error. The control slot HUGS. It was FIXED at 40px — the height of an Input — which silently clipped anything taller the moment one was swapped in: AccountColorPicker lost its second row and the drawer looked like it had six colours. An instance-swap slot cannot carry the height of its default occupant.
