Short explanation on hover or focus. Side = where it sits relative to the trigger, which is also where the arrow points. Inverts against the page — surface/inverse with foreground/on-inverse — so it reads as an overlay and never as part of the content underneath. Desktop only: there is no hover on touch. Anything a mobile user needs to know must be visible without one.
