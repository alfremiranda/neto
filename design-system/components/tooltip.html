Short explanation on hover or focus. Side = where it sits relative to the trigger, which is also where the arrow points. Inverts against the page — bg/inverse with fg/on-inverse — so it reads as an overlay and never as part of the content underneath. Content is an INSTANCE_SWAP, the same shape Sheet uses. The bubble owns the surface, the arrow, the cap at 320 and the inversion; what goes inside it is swappable. TooltipText is the default sentence. TooltipReadout is the data readout a chart needs. Forking the bubble to carry a table would have duplicated the inversion in two places. Desktop only: there is no hover on touch. Anything a mobile user needs to know must be visible without one — for a chart that means the selected point's figures belong in the card's own metrics, not only in this bubble.
