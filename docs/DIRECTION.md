## 1. Business model (decided 2026-07-30)

- **Freemium + subscription.** The free/paid line follows the existing empleado/independiente
  profile split: **Free** = the simple income/expense/accounts manager (empleado profile);
  **Pro** = the full tax engine (IBC, SS, FSS, retención), provisions, PILA calendar, effective-TRM
  calculator, full annual analytics, CSV export, priority multi-device sync.
- Target price: **~COP 19,900/mo or COP 149,900/yr**, founder lifetime discount for the first
  ~100–500 subscribers. Web billing likely via a merchant of record (Paddle/Lemon Squeezy) at start.
- **Strategy:** beachhead = Colombian independents billing in foreign currency, expanding in rings
  (all CO independents → empleados/general → LatAm). The configurable deduction engine is what makes
  the LatAm ring credible — keep tax rules as data, not code.
- **Privacy is a core differentiator.** Never ads, never data monetization. Local-first stays.
