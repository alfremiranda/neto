# FYI-page-titles
FYI, answering my own Q- from earlier (Alfredo settled it): "CUENTAS" is not an eyebrow, it is the
page title, so it takes Heading/Section — not Label/Micro. My classification was wrong.
Applying it consistently exposed that page titles had been carrying four different styles:
Display (login, consent, onboarding), Section (Dashboard), Subsection (Perfil, Configuración) and
Label/Micro (Cuentas, Ahorros — mine). All five in-app page titles are Heading/Section now.
Standalone screens with no app chrome keep Display — tell me if that split is wrong too.
