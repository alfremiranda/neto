# docs/inbox/orchestrator/ — questions for the orchestrator

Dev or Design drop `Q-YYYY-MM-DD-<slug>.md` here when they need a verification or a
cross-domain call MID-SESSION, instead of parking it in the report's NEEDS until close.
Same ≤10-line format: the question + a pointer + the options as you see them.

The orchestrator processes this folder on every daily sync and whenever Alfredo says
"inbox" to it. Answers come back as a file in YOUR inbox (dev/ or design/), a ticket, or a
DIRECTION.md change — and the Q moves to done/. Decisions that belong to Alfredo get
escalated by the orchestrator, not by you.

Report NEEDS still works and is still read — this folder is the fast lane, not a replacement.
