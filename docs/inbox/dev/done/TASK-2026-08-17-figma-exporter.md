# TASK-2026-08-17-figma-exporter

TASK: Build the Figma → `design-system/_build/tokens.json` exporter. `build.py` consumes that
file; **nothing in the repo produces it**, so `design-system/` cannot be regenerated from the
SSOT by anyone. "Figma is the SSOT and `design-system/` is a generated artifact" is true as
policy and false as mechanics. Verified in the working tree today, not quoted from a doc.

WHY NOW: Alfredo approved it into phase 1.5 (2026-08-17), where it is deliverable **D2**.
Measured cost of not having it: 31 Figma variables unpublished, 8 published keys with no source
in Figma, 2 values in disagreement (`docs/reports/2026-08-17-token-drift-measured.md`). Second
consequence, found today: the `account-accent/*` collection Design built in `ea786e1d` exists in
Figma and `grep account-accent design-system/tokens/*.css` returns nothing — it cannot reach the
app. Every ticket whose DONE WHEN says "`design-system/` regenerated" is unclosable until this
lands, which is why that clause is being retired system-wide in the meantime.

SCOPE: read Figma's variables and text styles and emit `_build/tokens.json` in exactly the shape
`build.py` already expects (`sem_light`, `sem_dark`, `cmp_light`, `cmp_dark`, `num`, `text`).
`build.py` then produces `design-system/` as it does today. **This is not a rewrite of
`build.py`** — if the two disagree, the exporter conforms to it.

SPLIT: you own the code. **Design owns the rename map** (Figma variable name → published key) and
the call on each of the 8 orphan keys — kill or adopt, one by one. Build the mechanism against
the map as it stands and **do not invent names for the orphans**; a guessed name becomes a
published token nobody decided.

DONE WHEN: `design-system/` regenerates from Figma reproducibly · the diff against today's
committed output is explainable line by line · the run is documented well enough that Design can
trigger it. Report the drift the first run surfaces instead of silently absorbing it — those 2
disagreeing values are a decision each, not a merge conflict.
